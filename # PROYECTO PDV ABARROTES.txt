# PROYECTO: PDV ABARROTES

Quiero construir un sistema completo de **Punto de Venta para una tienda de abarrotes**.

Ya existe la base de datos en **SQL Server**.

A partir de este momento quiero desarrollar EN PARALELO:

1. Backend / API REST en **.NET 9**.
2. Sistema PDV y administrativo en **React + TypeScript**.

El proyecto puede tomar como referencia técnica algunas buenas prácticas utilizadas anteriormente en el proyecto **PDV Lambrin**, especialmente:

* Arquitectura React → API .NET → SQL Server.
* API como única capa que accede a SQL Server.
* Paginación server-side.
* Auditoría.
* Bitácora.
* Seguridad.
* DTOs.
* Respuestas estandarizadas.
* Async/Await.
* Manejo global de errores.
* Documentación.
* Git por ramas.
* CHANGELOG.
* Pruebas.
* Paginación 25/50/100.
* Reportes optimizados.
* Separación frontend/backend.

IMPORTANTE:

**NO COPIAR LAS REGLAS DE NEGOCIO DE LAMBRIN.**

Este proyecto es diferente.

Este proyecto está enfocado exclusivamente en un:

# PDV DE ABARROTES

El sistema tendrá una carga operativa considerable debido a que puede existir una venta:

* Cada 5 minutos.
* Cada 2 minutos.
* Incluso cada 1 minuto en horarios de alta demanda.

Por ello el rendimiento, concurrencia, estabilidad, búsquedas rápidas y transacciones son requisitos principales.

# 11. ESCÁNER DE CÓDIGO DE BARRAS

El escáner es una funcionalidad principal del PDV.

Debe soportarse prioritariamente escáner físico USB/Bluetooth que funciona como teclado HID.

Flujo:

```text
Escanear
   ↓
Leer codigo
   ↓
Buscar producto
   ↓
Encontrar coincidencia exacta
   ↓
Agregar automáticamente
   ↓
Incrementar cantidad si ya existe
   ↓
Mantener foco listo para siguiente producto
```

Debe funcionar sin necesidad de utilizar mouse.

Si el lector envía ENTER después del código, utilizarlo para ejecutar automáticamente la búsqueda.

La consulta por código de barras debe ser extremadamente rápida.

Crear endpoint similar a:

```http
GET /api/v1/productos/codigo-barras/{codigo}
```

Buscar directamente en SQL.

NO:

```text
Cargar productos
→ filtrarlos en React
```

# 12. BUSCADOR DEL PDV

Quiero un buscador de productos muy preciso.

Ejemplo:

Si el cajero escribe:

```text
coca
```

deben aparecer resultados como:

```text
Coca Cola 600 ml
Coca Cola 1 L
Coca Cola 2 L
Coca Cola 3 L
Coca Cola Sin Azucar 600 ml
Coca Cola Lata
```

La búsqueda deberá analizar:

* Código de barras.
* Código interno.
* Descripción.
* Marca.
* Categoría cuando corresponda.

Prioridad aproximada:

```text
1. Codigo de barras exacto
2. Codigo interno exacto
3. Descripcion exacta
4. Descripcion que inicia con búsqueda
5. Palabras coincidentes
6. Descripcion que contiene búsqueda
```

Normalizar:

* Mayúsculas/minúsculas.
* Espacios.
* Acentos cuando sea posible.

Ejemplos:

```text
coca
coca cola
coca 600
coca sin azucar
```

deben producir resultados útiles.

En React utilizar:

```text
debounce
```

aproximadamente 300-500 ms para búsqueda escrita.

Cancelar consultas anteriores cuando el usuario continúe escribiendo.

Evitar solicitudes duplicadas.

El filtrado principal debe ejecutarse en SQL Server, NO en memoria de React.
